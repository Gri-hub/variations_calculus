# variations_calculus

## Требуемые пакеты

При разработке сборка проекта производилась на OS Linux Ubuntu.

Для сборки проекта необходимы следующие пакеты:
```text
texlive-latex-base
texlive-fonts-recommended
texlive-fonts-extra
texlive-latex-extra
texlive-lang-cyrillic

```

## Инструкция по сборке

Скопируйте проект в рабочую директорию вашего ПК. Поскольку мы используем утилиту `latexrun` (подключенную как git submodule) 
для более информативных сообщений сборки и поддержания чистоты проекта, рекомендуется клонировать репозиторий сразу со всеми сабмодулями:

```bash
git clone --recurse-submodules git@github.com:Gri-hub/variations_calculus.git

```

*(Если вы уже клонировали проект без этого флага, инициализировать и скачать `latexrun` можно командой: `git submodule update --init --recursive`)*

Запустите скрипт, устанавливающий необходимые зависимости (если применимо):

```bash
sudo ./configure.sh

```

Для сборки проекта в корневом каталоге лежит `Makefile`. Чтобы запустить автоматическую сборку в рабочей директории, выполните команду:

```bash
make

```

Благодаря утилите `latexrun`, ваша корневая директория останется чистой: все вспомогательные файлы 
с расширениями `.aux`, `.bbl`, `.blg`, `.log`, `.out`, `.toc` будут спрятаны в отдельную директорию (обычно `latex.out/`), 
а в корневом каталоге появится только итоговый файл `main.pdf`.

Для того, чтобы очистить рабочую директорию от вспомогательных файлов кэша сборки, выполните в терминале команду:

```bash
make clean

```

При этом внутренние папки с логами будут удалены. Для повторной сборки проекта снова выполните команду `make`.

### Сборка в онлайн редакторе Overleaf

Сборку данного проекта возможно провести в онлайн LaTeX редакторе [Overleaf](https://ru.overleaf.com/login). 
Создайте новый проект и удалите все автоматически созданные файлы. Загрузите с вашего компьютера все файлы и папки (сохраняя структуру), 
кроме служебных: `.gitignore`, `.gitmodules`, папки `latexrun`, `Makefile`, `LICENSE` и `README.md`. Откройте в Overleaf файл `main.tex` 
и нажмите на кнопку **Recompile**.
